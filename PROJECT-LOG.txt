HOW TO READ THIS LOG

Dates and times are in Asia/Dhaka (UTC+06:00). Exact times identify a
Git commit or a local verification checkpoint as indicated. They are not
necessarily the time a feature was first written or made public. Earlier
undated work is grouped under the first commit that records it. Local work
and published releases are identified separately. The release changelog
summarizes versions. This log records individual milestones, decisions,
reversals, and verification.

PROJECT MAP

Desktop: CircuitBench. A Python/PyQt6 schematic editor with bundled
ngspice 47 for Windows x64. Device placement, wire connectivity, project
storage, SPICE generation, runs, and plot exports live primarily in
app.py, canvas.py, circuit.py, results.py, and plotting.py. Reusable
subcircuit editing also uses subcircuit_designer.py.

Web: CircuitBench-Web in the workspace. The publishing checkout observed
in this workspace is CircuitBench/.build/CircuitBench-Web, with the web
app under web/. JavaScript handles the UI. Pyodide runs the shared Python
core. The browser uses ngspice 46 via WebAssembly and stores run history
locally. The static build is deployed through GitHub Pages.

Distribution: The desktop development repository is private. The public
CircuitBench-Releases repository contains download information and release
assets. Its executable is distributed with the matching GPLv3 source
archive. The deployed web app has its own repository and release path.

Initial work through 2026-11-26 03:50 — Desktop foundation and 0.1 beta
    Commit: d7ceb3d, tagged v0.1-beta.
    The initial desktop preview established an independent workbench for
    schematic preparation and SPICE simulation. Historical PSpice/OrCAD

    cursors and pins, CSV and image/PDF export. The app imported supported
    SPICE model cards and subcircuits plus the bundled starter models and
    Qucs-S diode catalog. The Windows x64 EXE bundled Qt and ngspice 47.
    Verification: the initial recorded build exercised model import,
    a 5 V divider, a 201-point AC sweep, and PNG/PDF export.

    Local evidence: reusable-subcircuit-smoke.json.

2026-11-26 20:01 — Plus/minus labels and shared return ports
    Local evidence: rc-port-alias-smoke.json.
    Fixed the invalid-net-label error on an RC filter drawn with In+,
    In−, Out+, and Out−. The compiler accepts signed labels and
    normalizes Unicode minus. The designer proposes ports from named
    nets. Multiple visible ports mapped to one net are internally
    connected, and SPICE uses one connection per distinct electrical
    port. The example therefore has four visible pins and three nets.
    Operating-point instrumentation skips individual current probes on
    shared ports. A current marker on an external component can measure
    a branch of the common return.
    Verified that the designer recognizes all four labels and tested the
    RC circuit in ngspice with both return pins in use. All 42 desktop
    tests and the packaged Windows smoke passed.
