# CircuitBench

CircuitBench is a Windows desktop workbench for drawing electronic schematics, running ngspice simulations, and analyzing waveforms. It supports quick circuit checks and repeatable design studies in the same project.

**[Download CircuitBench for Windows](https://github.com/tonmoypaul2003/CircuitBench/releases/latest/download/CircuitBench.exe)** · [Release notes](https://github.com/tonmoypaul2003/CircuitBench/releases/latest)

## What you can do

- Draw schematics with built-in components, import SPICE models, and reuse your own subcircuits.
- Run operating-point, AC, transient, and noise analyses, along with parameter sweeps and design studies.
- Inspect waveforms with cursors and measurements, review saved runs, and export plots, data, and PDF reports.

The Windows x64 executable includes ngspice. To try a circuit, open **File → Examples**, load the voltage divider, and press **F5**.
